# Revisão Prova 2 - Implementação a Banco de Dados

1) Triggers 
    - Executa automaticamente uma ação quando ocorre um: INSERT, UPDATE ou DELETE em uma tabela 
2) Transaction 
    - Operações tratadas em uma unica unidade, permitindo confirmar ou desfazer as alterações
    - BEGIN TRAN
        -  Inicia uma transação
    - COMMIT 
        - Confirma as alterações 
    - ROLLBACK 
        - Dezfaz as alterações
4) View 
    - Permite consultar informações de uma ou mais tabelas sem precisar escrever a consulta completa
